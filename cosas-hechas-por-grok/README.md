## Cómo verlas

### Opción 1 – Ver el código
Simplemente haz clic en cualquiera de los archivos `.html` de esta carpeta.

### Opción 2 – Verlas como páginas web (recomendado)
1. Ve a **Settings → Pages** de este repositorio.
2. En **Source** elige la rama `main` y la carpeta `/ (root)` o `/docs`.
3. Guarda.
4. Después de unos minutos las páginas estarán disponibles en:

**https://playerssssssss.github.io/buscador/cosas-hechas-por-grok/**
